# Divas Video v45 · menos controles, más vídeo

## Recorrido en el teléfono

1. **Crear vídeo → Añadir vídeo o foto.** El archivo aparece grande en el lienzo. Debajo hay reproducción, el tiempo y una pista compacta.
2. **Toca un elemento.** El nombre sobre el lienzo identifica la selección. Puedes arrastrarlo sin abrir menús. El candado y la cruz sirven para bloquear y eliminar; **Listo** junto al nombre quita la selección.
3. **Elige una acción.** Con una imagen o vídeo seleccionado aparecen **Editar, Quitar fondo, Añadir, Capas y Más**. Con un texto, las primeras opciones son **Editar texto y Tamaño**. Sin selección aparecen **Añadir, Texto, Música, Capas y Formato**.
4. **Ajusta viendo el resultado.** Solo se abre un panel inferior. **Listo** lo cierra. Los detalles menos frecuentes están en desplegables; no se pierden funciones.
5. **Exportar.** La calidad se elige en el menú superior **Divas Video ···**. Guardar el avance y exportar el vídeo son acciones diferentes.

## Dónde está cada cosa

| Necesidad | Recorrido |
| --- | --- |
| Tamaño, encuadre y forma | Seleccionar → Editar |
| Giro, coordenadas, opacidad y animación | Editar → Posición, opacidad y animación |
| Duración, dividir, Superponer / En secuencia | Editar → Tiempo; también Más → Tiempo y recorte |
| Luz y color | Editar → Color |
| Texto independiente | Añadir → Añadir texto; sin selección, Texto |
| Voz o música | Más → Audio y volumen; sin selección, Música |
| Orden visual | Capas → arrastrar por el asa o usar Delante / Detrás |
| Todas las pistas de tiempo | Ampliar junto a la reproducción |
| Duplicar, ocultar o eliminar | Más; la cruz sobre el lienzo también elimina |
| Nombre, formato, calidad, fondo y respaldo | Divas Video ··· |
| Volver a los proyectos | Divas Video ··· → Mis proyectos |
| Ver el resultado sin controles | Icono de ampliar junto al formato → Editar para volver |

**Quitar fondo** conserva Antes / Después / Comparar / Transparencia. Elegir el color prepara una vista previa. Confirmar aplica el recorte y vuelve al lienzo; Cancelar conserva el anterior. El panel no se puede cerrar dejando una confirmación oculta. **Bordes y protección del logo** contiene el alcance exterior/global, suavizado y limpieza. Los presets blanco/negro siguen protegiendo el detalle interior mediante el modo exterior de v44.

Los vídeos y sus archivos siguen guardándose en este navegador y separados por cuenta. El nuevo menú lo explica y ofrece respaldo editable. No se migra almacenamiento, no se modifica Supabase y no se borran proyectos.

## Referencias de interacción

Se revisaron las guías oficiales de [CapCut para principiantes](https://www.capcut.com/resource/capcut-tutorial-for-beginners) y [Adobe Express móvil](https://helpx.adobe.com/express/mobile/video-creation-and-editing/create-videos/create-videos.html). La comparación se centra en los recorridos documentados, no en una auditoría de todas sus versiones ni de sus funciones de pago.

| Referencia | Aplicación en Divas |
| --- | --- |
| CapCut: empezar con archivos, seleccionar el clip y acceder a sus herramientas | Añadir como inicio claro y acciones dependientes de la selección |
| Adobe Express: separar la edición de escenas/tiempo de los ajustes del elemento | Pista compacta para tiempo y panel para la herramienta solicitada |
| Ambas: terminar con exportación | Exportar permanece en la cabecera; el respaldo se reúne con el proyecto |

Divas conserva su motor propio, su paleta rosa y el editor de PC. El objetivo de esta versión es reducir las decisiones simultáneas; no se incorporan bibliotecas adicionales ni código de esos productos.

## Comprobación y alcance

Se verificaron vistas táctiles de 320 a 390 px, alturas de 568 a 844 px, orientación horizontal, temas claro/oscuro, movimiento reducido y PC. Se comprobaron recorte con píxeles, movimiento táctil, capas, guardado, respaldo y vídeo exportado. Ver [pruebas](../tests/README-video.md).

La edición en pantallas muy cortas prioriza el campo activo y deja Listo accesible. El teclado se probó reduciendo el viewport; hace falta validación adicional en dispositivos reales. La exportación y el rendimiento dependen del navegador, códec y tamaño de los medios.
